Installation
============

Install directly from GitHub with ``pip``::

   pip install git+https://github.com/jyurkiw/sim-template-cli.git

or with ``uv``::

   uv pip install git+https://github.com/jyurkiw/sim-template-cli.git

Both install an ``mct`` executable directly onto your ``PATH``. You can run
``mct`` directly afterward — no ``python -m`` or ``uv run`` prefix needed.
